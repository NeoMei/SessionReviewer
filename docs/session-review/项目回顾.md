<!-- session-reviewer:risk id="open-loop-skill-installer-executable-bits" -->
### 让 GitHub Skill 安装后保留 POSIX wrapper 可执行性
#### 状态
open
#### 详情
问题：如何让用户从 GitHub 安装 session-reviewer Skill 后，无需手工 chmod 就能直接运行 POSIX wrappers？
阻塞：GitHub Skill 安装器的下载或落盘过程未保留 POSIX 执行位。
下一实验：评估将 Skill 调用改为显式 sh wrapper，或提供可验证的安装后 chmod 机制，并在干净 macOS/Linux 环境复验。
完成标准：从 GitHub 全新安装后，两个 POSIX wrapper 无需手工修复即可完成 prepare 与 apply 工作流。
已尝试：确认源码和 v0.1.0 Release 归档中的两个 .sh wrapper 均为 0755。；确认 GitHub Skill 安装器落盘后两个 wrapper 变为 0644，直接执行返回 126。；当前本机已手工恢复 0755，并完成 wrapper、checkpoint、resume、status 与 dry-run 验证。
<!-- /session-reviewer:risk -->
