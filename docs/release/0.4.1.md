## 使用与升级边界

本版 CLI 与插件统一为 `0.4.1`，匹配 v4 Markdown 的最低读写能力声明。
升级前请备份已有回顾/历史文件和本机接受状态。旧项目可在保留备份后自行明确发起扫描；安装或升级本身不自动重扫，不删除或覆盖人工内容，也不将真实旧项目迁移视为已验收。

v4 项目视图当前提供原生文档入口和只读状态刷新，不包含旧版内联结构编辑器、问题归位操作或扫描按钮。编辑允许的人类正文后，通过 CLI 执行 `session-reviewer sync`；扫描使用 `session-reviewer scan --json`。公开文件有效不等于私有接受状态已验证。

问题拆分/归位推荐、后续确定性 Session 摘要等独立功能任务不属于本次已交付清单。额外跨平台人工验收与真实旧项目迁移不在本次范围；下载包的存在不代表各最低操作系统版本均已实机验收。
