**Goal:** Turn docs/session-review/project-overview.md into the obvious recovery homepage, add a bounded five-node Mermaid evolution path and Chinese directory indexes/quick summaries, and publish the same canonical generated content safely to Project, Obsidian Vault, and merge Base.

**Architecture:** Keep the accepted ledger as the only semantic source. A focused renderer in internal/ledger deterministically produces generated sections plus standalone derived files; apply incorporates those bytes into its existing all-file WritePlan, while sync treats generated sections as non-semantic units and runs a recoverable derived-publication phase only after semantic reconciliation succeeds. The publication journal stores only hashes and stages, rerenders from the final Project ledger during recovery, and advances Base only after Project and Vault verify identical canonical entity bytes.

**Tech Stack:** Go 1.26; Go standard library including os.Root; gopkg.in/yaml.v3 v3.0.1; github.com/yuin/goldmark v1.8.2; existing internal/ledger, internal/accounting, internal/syncdoc, internal/sync, internal/pathguard, internal/atomicfile, internal/platform, and CLI packages; GitHub Actions macOS and Windows runners; Markdown and Mermaid.

## Global Constraints

- project-overview.md remains the unique normal-user entry point and keeps its stable project-overview identity.
- The homepage Mermaid uses exactly five high-level nodes in this order: 项目目标 → 关键决策汇总 → 最近已验证里程碑 → 当前状态 → 下一步.
- Homepage recent changes and verified milestones are each limited to the newest three items; truncation is Unicode-rune safe.
- decisions/00-目录说明.md, open-loops/00-目录说明.md, and sessions/00-目录说明.md are standalone generated files and never enter accepted-ledger or normal sync inventories.
- Homepage 项目导航 and entity 快速理解 sections are generator-owned, do not count as human semantic edits, do not increment revision, and are restored from accepted state after manual modification or deletion.
- Unknown human frontmatter and unknown non-generated sections remain lossless and editable under the existing Base/Project/Vault merge contract.
- Rendering is deterministic and model-free; it adds no schema fields, renames no stable entity files, invokes no Git automation, and does not introduce Canvas/Excalidraw as the default view.
- Standard relative Markdown links must work in GitHub Markdown, Obsidian, and ordinary editors; Mermaid text, Markdown labels, and URL paths use separate escaping functions.
- All generated bytes, path keys, file budgets, and the combined manifest hash are validated before the first write.
- Derived sync publication runs only when ordinary reconciliation has no conflict, scan issue, or entity error; interrupted publication returns nonzero and remains recoverable.
- Repeating apply or sync against the same accepted state produces identical bytes and no file modification.
- Preserve existing SaveRoot/transaction recovery backups and root-confined regular-file operations; reject redirects, symlinks, Windows reparse/path collisions, non-regular files, and parent identity changes.
- Cross-platform acceptance covers macOS Intel/Apple Silicon build behavior and Windows x64 path/build behavior.

func (d Document) SemanticUnits() UnitSet {
    result := make(UnitSet)
    for key, unit := range d.Units() {
        if key.Kind == UnitSection && generatedSectionKey(key) { continue }
        result[key] = cloneUnit(unit)
    }
    return result
}

func (d Document) WithSemanticUnits(input UnitSet) (Document, error) {
    combined := d.Units()
    for key := range combined {
        if !(key.Kind == UnitSection && generatedSectionKey(key)) {
            delete(combined, key)
        }
    }
    for key, value := range input {
        if key.Kind == UnitSection && generatedSectionKey(key) {
            return Document{}, ErrReservedField
        }
        combined[key] = cloneUnit(value)
    }
    return d.WithUnits(combined)
}

func (engine *Engine) publishDerived(ctx context.Context, plan derivedPlan) error {
    txn := Transaction{
        Version: 1, Kind: TxnDerivedPublish, EntityID: derivedTransactionID,
        DesiredHash: plan.manifestHash, ExpectedBaseHash: plan.semanticHash,
        Stage: TxnPlanned, UpdatedAt: engine.options.Now().UTC(),
    }
    if err := engine.transactions.Save(txn); err != nil { return err }
    if err := engine.writeDerivedSide(ctx, SideProject, plan); err != nil { return err }
    if err := engine.advanceDerived(&txn, TxnProjectWritten); err != nil { return err }
    if err := engine.writeDerivedSide(ctx, SideVault, plan); err != nil { return err }
    if err := engine.advanceDerived(&txn, TxnVaultWritten); err != nil { return err }
    if err := engine.commitDerivedBases(plan); err != nil { return err }
    if err := engine.advanceDerived(&txn, TxnBaseCommitted); err != nil { return err }
    return engine.transactions.Remove(derivedTransactionID)
}
~~~
